# Day14

## 実施内容

- DTC記録の永続化機能を実装した（persist.h / persist.cを新規作成）
- DtcRecord⇔テキスト変換（ロジック）とファイル読み書き（I/O）を関数単位で分離した
- previous（エッジ検出用の前回状態）は保存対象に含めない設計にした
- main.cに起動時の読み込み・終了時の保存を組み込んだ
- 読み込み・保存の成功/失敗を[PERSIST]タグ付きログで表示するようにした

## 確認・検証

| 確認観点 | 結果 |
| --- | --- |
| ビルド（-Wall -Wextra -std=c11） | 警告・エラーなし |
| テストビルド（make test） | 31 passed, 0 failed（既存テストに影響なし） |
| 実行確認（make run） | 1回目実行でファイルが生成され、2回目実行で発生回数が継続・加算されること、Freeze Frameが上書きされないことを確認した |

## 今回の設計方針

- 保存タイミングは終了時に1回、読み込みは起動時に1回とした（テキスト形式）
- 永続化はDTC専用の1モジュール（persist.c）とし、汎用的な保存層は作らなかった（今DTC以外に永続化対象が無いため）
- previousは一時的な内部状態のため保存対象に含めず、読み込み時は常にNORMALから再開する
- ログ表示の責務はmain.cではなくpersist.c側に置いた（他モジュールと同じく処理と表示を同じモジュールに持たせるため）
