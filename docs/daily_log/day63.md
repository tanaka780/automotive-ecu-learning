# Day63

## 実施内容

- `src/validate.c`・`src/sensor.c`・`include/status.h`・`include/alert.h`・`include/fan_ctrl.h`の水温の値域と閾値を、実車に近い値に変えた（値域25〜130℃、注意100℃超、危険110℃超、ファンは95℃でON・90℃でOFF）
- `sim/fixture.c`で、`TEMP=`・`TEMP@N=`に`OPEN`・`SHORT`を書けるようにした（断線・ショートを、値域外の値0・255で再現するため）
- `src/status.c`に値域外の段階を足した（高い側の値域外を、危険と区別するため）
- `src/faultmgr.c`で、水温は値域外の継続で故障を確定し、値域内の継続で復帰するようにした。確定までは、値域外の値を直前の正しい値に差し替える
- `src/diag.c`で、値域外に入った瞬間もDTCとして数えるようにした
- `src/can.c`・`src/main.c`・`src/meter.c`で、警告灯データに高温の通知を足し、メーターで表示するようにした。水温センサーの故障中は、メーターの水温を「--」と表示する
- `src/fan_ecu.c`で、強制ONが解けた後は、使える水温が決まるまでONを保つようにした（故障の解除直後に、ファンが一瞬止まっていたため）
- `test/`の単体テストを新しい目盛りと決まりに合わせて直し、値域外の判定・確定と復帰・直前の値への差し替え・高温の判断・高温のビットの往復・ファンをONに保つことのテストを足した（154→174件）
- `scenario_test/`の結合テストを新しい目盛りの筋書きに作り直し、オーバーヒート、オーバーヒート中の水温センサーの故障、最初から故障していて高温で直る、の条件を足した（55→74件）

## 判定

Phase27で決めたとおりに、オーバーヒートと水温センサーの故障を区別できるようになった。

- 3つの場合とも、結合テストの期待と一致した。オーバーヒートは置き換えずに警告と高温の通知が続き、故障は値域外が3回続いた秒に確定してメーターは「--」になり、オーバーヒート中の故障では高温の通知が最後まで残った
- 関係しない場面は、変更の前後で比べた3つの段階でも、Phase27の前との比較でも、表示の形が変わった所（` overheat=0`）を除いて全文が一致した
- わざと入れた誤りは、どれも単体か結合のテストで落ちた。結合で見張れないのは、今は起こせない値域外の車速・回転数などで、理由ははっきりしている
- ファンが一瞬止まる不具合は、直す前に仮想時間版で毎回同じ秒に起き、直した後は仮想時間版・実時間版のどちらでも起きなかった
- 再生画面のデータは本体の出力と一致し、READMEに書いた手順で図と画像を作り直せた

## 今回の設計方針

- 段階を6つに分け、3つの段階（値域外の起こし方・高温の通知と表示・ファンの修正）では、変更の前の実行ファイルを残して、関係しない場面の出力を全文で比べた。どの変更で何が変わったかを、出力の差で言えるようにするため
- 車速・回転数の値域外は、決めた内容に無かったので、危険より悪い値として確定の側に数え、確定前は直前の値に差し替えることにした。値域外の段階を全センサーに足したので、扱いをそろえた
- 高温の判断は、状態判定と同じ関数・同じ閾値を、判断に使える水温（値域外なら直前の正しい値）に当てて行う。オーバーヒートの途中で壊れたときに通知を残すため
- オーバーヒート中に故障が確定すると、警告ログは止まるが高温の通知は残る。運転手に届くのは通知の方なので、このずれは受け入れ、既知の制約に書いた
- DTCの表示の文言（`CRITICAL occurrences`）は、結合テストと再生画面が読んでいるので変えず、記録の種類を分ける次のテーマで扱う
- ファンが一瞬止まる不具合は、確定までの値の段階を確かめるときに、別の条件を動かして見つけた。その段階の変更の前に戻しても同じ出力だったので、その段階ではなく`fan_ecu.c`の作りの問題と判断し、Phase27の中で直した
- ファンの結合テストの水温センサー故障の条件は、「100℃でファンが回っている途中で断線」に変えた。確定前の秒にメーターが表示する値が、状態判定の段階（値域外の値は受信側で捨てられ、前に届いた値のまま）と確定までの値の段階（直前の正しい値が届く）のどちらでも同じ100℃になり、筋書きを2回作り直さずに済む
- 再生画面は、水温115℃で「センサーの異常」を起こしていた5つの場面を断線・ショートで起こす形に直し、READMEの表の動きが全部見られるよう3場面を足した。危険に入った秒の文は、その秒に警告が実際に出たかを見て書き分ける
