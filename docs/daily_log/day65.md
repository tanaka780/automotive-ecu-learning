# Day65

## 実施内容

- `src/main.c`・`include/diag.h`・`src/diag.c`で、実行の途中でエンジンをかけ直したとき（イグニッションOFF→ON）に、エンジン監視ECU役の判断の状態（故障の確定・連続回数・直前の値）と、記録の前回の異常の有無を戻すようにした（`diag_reset_previous`）。記録の回数・状態区分・フリーズフレームと統計は残す
- `include/can.h`・`src/can.c`・`src/fan_ecu.c`・`include/meter.h`・`src/meter.c`で、かけ直したときに、メーターECU役・ファン制御ECU役の受信監視状態の途絶の連続回数と状態を戻すようにした（`can_monitor_restart`。送信時刻の記録は残す）。メーターECU役も、かけ直しを自分で見つける
- `include/persist.h`・`src/persist.c`・`src/main.c`で、メーターECU役・ファン制御ECU役の通信の途絶の記録を、ECUごとのファイル（`meter_dtc.txt`・`fan_dtc.txt`）に保存し、次の起動で読み込むようにした（Phase29）
- `include/cmd.h`・`src/cmd.c`で、点検コマンドの`clear`（対象を指定しない）で、3つのECUの記録を全部消すようにした（Phase29）
- `test/`の単体テストに、かけ直したときの戻し方、通信の途絶の記録の保存・読み込み、`clear`での消し方のテストを足した（176→185件）
- `scenario_test/`の結合テストに、途中でかけ直す5条件と、通信の途絶の記録の引き継ぎ・`clear`を5回続けて起動して確かめる条件を足した（79→90件）。点検コマンドを入力できるよう、実行の関数に標準入力の文字列を渡せるようにした

## 判定

段階A・Bで「エンジンをかけ直したら、どのECU役も起動したときと同じく判断をやり直し、記録は残す」にそろい、Phase29で決めたとおりに、通信の途絶の記録を残して消せるようになった。

- かけ直した後の動きは、どの条件も起動直後と同じ形になった（通電してから3回目に確定する）
- 関係しない条件の出力は、どの段階でも全文一致した。違いが出たのは、見込んだ条件と行だけだった
- わざと入れた誤りは、どれも単体か結合のテストで落ちた。最初に落ちなかった2つは、テストの値と条件が見分けられない形だったためで、直した後は落ちた
- 本番版の4回とも、記録の引き継ぎと消え方が期待と一致した

## 今回の設計方針

- かけ直しを「起動し直したのと同じ」とした。study_plan.mdの車両シナリオはイグニッションOFFをECUが止まることとして扱っており、ファン制御ECU役は前からかけ直したときに判断の状態を戻していた。ただし切る前からの断線や途絶が、かけ直した後も続いていると、確定し直すまでの2秒間はファンを回さない。前は切る前の確定が残っていてすぐ回っていたが、起動直後と同じ動きとして受け入れ、既知の制約に書いた
- 受信監視状態は、連続回数と途絶の状態だけを戻し、送信時刻の記録は残した。busはOFFの間も最後のフレームを持ち続けるので、送信時刻まで戻すと、OFF前の古いフレームを新しいものと見誤る
- 段階A・BはPhaseを立てなかった。シナリオどおりに動いていなかった所を合わせる直しで、Day58の`fan_ecu.c`の直しと同じ扱い
- 通信の途絶の記録はECUごとのファイルに保存し、保存処理は`persist.c`に置き、起動時自己診断は変えなかった
- 保存のログのタグは`[PERSIST]`にした。最初は表示と同じ`[CAN-DTC]`にするつもりだったが、結合テスト（`test_fan_control.py`）が`[CAN-DTC]`で始まる行に必ず`NONE`があることを確かめており、再生画面のデータ作りもその行を記録として集めるので、どちらも取り違える。文の中は、ファイル名と合わせてECUの名前（meter/fan）にした
- `clear`（対象を指定しない）で、ほかのECUの記録も消すことにした。UDSは行わないと決めているので、エンジン監視ECUだけを消す形にすると、保存するようになった2つの記録を消す方法が、ファイルを手で消すことしかなくなる。全部のECUを消すと決めるのは`cmd.c`なので、ログも`cmd.c`が`[CMD]`で1行出す
- 記録の取り違えを見張る結合テストは、ファン状態の送信を止める条件にした。途絶を記録するのがメーターECU役だけになり、2つのファイルの中身が違うので、互いのファイルに保存すると次の起動で食い違う
